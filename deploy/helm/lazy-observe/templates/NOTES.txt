{{- if eq .Values.mode "standalone-ha" }}
Before the pods start, create Secret {{ include "lazy-observe.secretName" . }} with at least:
  kubectl create secret generic {{ include "lazy-observe.secretName" . }} \
    --from-literal={{ .Values.secret.keys.postgresURL }}='postgres://...' \
    --from-literal={{ .Values.secret.keys.redisPassword }}='...' \
    --from-literal={{ .Values.secret.keys.s3AccessKey }}='...' \
    --from-literal={{ .Values.secret.keys.s3SecretKey }}='...'
All replicas share PostgreSQL, Redis, S3, VictoriaMetrics, VictoriaLogs, and VictoriaTraces.
Use values-standalone-ha-cluster.yaml as the clustered-storage reference:
  - metrics queryURL targets vmselect and ingestURL targets vminsert;
  - logs.url routes /insert/* to vlinsert and /select/* to vlselect;
  - traces.url routes /insert/* to vtinsert and /select/* to vtselect.
{{- else }}
This mode runs exactly one replica with embedded storage and a {{ .Values.persistence.size }} PVC.
{{- end }}

{{- $keySource := include "lazy-observe.encryptionKey.source" . }}
{{- $keySecret := include "lazy-observe.encryptionKey.secretName" . }}

Platform encryption key (seals stored secrets such as the AI API key):
{{- if eq $keySource "existing" }}
  All replicas read key {{ .Values.encryptionKey.key }} of your Secret {{ $keySecret }}, mounted read-only.
  The pods do not start until that Secret and key exist.
{{- else if eq $keySource "generated" }}
  All replicas read Secret {{ $keySecret }}, generated by this chart on first install.
  helm upgrade reuses it and helm uninstall keeps it (helm.sh/resource-policy: keep).
  helm template, client-side --dry-run and Argo CD cannot look it up and render a new key on
  every run; switch to encryptionKey.existingSecret for those workflows.
  Back the key up; without it, stored secrets (for example the AI API key) cannot be decrypted:
    kubectl get secret {{ $keySecret }} -n {{ .Release.Namespace }} -o yaml > {{ $keySecret }}.yaml
{{- else if eq .Values.mode "allinone" }}
  Stored as /data/secret.key on the PVC; it survives restarts as long as the PVC does.
{{- else }}
  WARNING: no Secret is configured, so the pod keeps the key in its emptyDir data_dir and
  generates a new one after every restart. Set encryptionKey.existingSecret or
  encryptionKey.autoGenerate=true.
{{- end }}

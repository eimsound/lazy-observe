{{- $keySource := include "lazy-observe.encryptionKey.source" . }}
{{- $keySecret := include "lazy-observe.encryptionKey.secretName" . }}

Platform encryption key (seals stored secrets such as the AI API key):
{{- if eq $keySource "existing" }}
  All replicas read key {{ .Values.encryptionKey.key }} of your Secret {{ $keySecret }}, mounted read-only.
  The pods do not start until that Secret and key exist.
{{- else if eq $keySource "generated" }}
  All replicas read Secret {{ $keySecret }}, generated by this chart on first install.
  helm upgrade reuses it and helm uninstall keeps it (helm.sh/resource-policy: keep).
  helm template, client-side --dry-run and Argo CD cannot look it up and render a new key on
  every run; switch to encryptionKey.existingSecret for those workflows.
  Back the key up; without it, stored secrets (for example the AI API key) cannot be decrypted:
    kubectl get secret {{ $keySecret }} -n {{ .Release.Namespace }} -o yaml > {{ $keySecret }}.yaml
{{- else if eq .Values.mode "allinone" }}
  Stored as /data/secret.key on the PVC; it survives restarts as long as the PVC does.
{{- else }}
{{- fail "encryptionKey: this mode cannot keep a key in data_dir; set encryptionKey.existingSecret or encryptionKey.autoGenerate=true" }}
{{- end }}

{{- $adminSource := include "lazy-observe.adminPassword.source" . }}
{{- $adminSecret := include "lazy-observe.adminPassword.secretName" . }}

First admin login (username admin). The password below is only used if the metadata database
has no admin yet; an admin created by an earlier install keeps its current password.
{{- if eq $adminSource "existing" }}
  All replicas read key {{ .Values.adminPassword.key }} of your Secret {{ $adminSecret }}, mounted read-only.
  The pods do not start until that Secret and key exist.
{{- else if eq $adminSource "generated" }}
  Generated by this chart on first install and shared by all replicas:
    kubectl get secret {{ $adminSecret }} -n {{ .Release.Namespace }} -o jsonpath='{.data.{{ .Values.adminPassword.key }}}' | base64 -d
  Anyone who can read Secrets in this namespace can read it: change it after the first login
  (Settings > Password). The Secret is not updated by that change. helm template, client-side
  --dry-run and Argo CD render a new value on every run; use adminPassword.existingSecret there.
{{- else }}
  No Secret is configured: the pod that creates the admin writes a random password to
  /data/initial-admin-password (mode 0600) and logs only that path. The image has no shell, so
  read it through an ephemeral debug container, for example:
    kubectl debug -it deploy/{{ include "lazy-observe.fullname" . }} -n {{ .Release.Namespace }} --image=busybox:stable \
      --target=lazy-observe --profile=sysadmin -- cat /proc/1/root/data/initial-admin-password
  The first login must change it before anything else works.
{{- if not (and (eq .Values.mode "allinone") .Values.persistence.enabled) }}
  WARNING: /data is an emptyDir here; if the pod restarts before you read the file, the password is
  lost. Set adminPassword.existingSecret or adminPassword.autoGenerate=true.
{{- end }}
{{- end }}

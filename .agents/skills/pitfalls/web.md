# Web 控制台防坑参考（`web/`）

适用于控制台鉴权、路由守卫、查询工作台及各类业务与系统管理页面的改动与审查。

## 1. 登录与改密安全跳转（`#181`）

- 校验 `redirect` 目标时要求路径以单个 `/` 开头，且第二字符既非 `/` 也非 `\`（或通过 `new URL(redirect, window.location.origin)` 校验同源 `origin` 严格相等），阻断 `//evil.example` 与 `/\evil.example` 开放重定向。
- 登录页（`login-page.tsx`）与强制改密页（`change-password-page.tsx`）共用同一安全跳转校验工具，回退默认页统一为站内相对路径。

## 2. 区分 401 会话过期与 403/404 业务错误（`#181`、`#183`）

- 全局会话过期拦截器（如 `session-expiry.ts`）仅对真正的认证失效（401）执行登出跳转；项目不存在（404）、权限不足（403）或上游探测失败（502）作为业务错误交给页面显式提示，防止误踢登出、循环重定向或将 403 吞成假空状态。
- 页面入口与后端 RBAC 契约保持一致：允许 `member` 读取配置告警规则所需的脱敏渠道摘要，渠道测试返回 502 等非 2xx 错误时直接呈现失败原因而非静默吞掉。

## 3. 通知渠道与弹窗敏感信息零回显、零残留（`#183`）

- 通知渠道卡片与列表按白名单字段渲染（名称、类型、脱敏目标），严禁使用 `Object.values(ch.config)[0]` 等通配遍历直接展示配置值，防止 Webhook Token、SMTP 密钥等敏感字段明文回显。
- 敏感或实体编辑弹窗一律条件挂载，实体编辑弹窗另绑实体 `key`（禁止常驻挂载；已有弹窗由 `architecture-guards.test.ts` 守护），杜绝跨对象残留明文临时密码或表单草稿。

## 4. 前后端字段、单位与分页契约对齐（`#181`、`#183`）

- 请求体与响应体字段与网关真实 DTO 严格对齐，重点核对：AI Assistant `assistantQuery` / `assistantExplain` 的上下文与时间参数、用户创建接口的 `display_name`、`/healthz` 中 `error_inbox` 等健康状态字符串的解析逻辑（避免把合法健康字符串误判为 `unavailable` 标红）。
- 概览与图表指标显式核对前后端物理单位：区分秒与毫秒（1000×，如 Overview P95 延迟）、区分 0–1 比例与 0–100 百分比（100×，如错误率），并在转换点写明单位。
- 游标分页（如审计日志）完整维护分页历史栈，确保翻页后可正确返回第 1 页；配置表单（如 AI Settings、AlertConfigCard）区分服务端同步数据与本地未保存草稿，防止定时刷新覆盖用户输入。

## 5. 跨项目与跨用户缓存及视图状态隔离（`#181`、`#183`）

- React Query 缓存键包含 `projectId`（用户态视图同时关联当前用户），切换项目或切换登录账号时按前缀清理或重置缓存。
- Metrics / PromQL 编辑器草稿、AI 对话历史及火焰图等页面状态按项目作用域隔离；当接口返回 404 或空数据时同步清空上一次的火焰图或查询结果，避免旧项目或旧时间窗数据残留误导排查。

## 6. Trace 树破环与显式栈遍历（`#181`）

- 构建 Trace span 树时对重复 `spanID` 去重、将缺失父节点或破环后的 span 提升为根节点，并用显式栈配合 `visited` 集合迭代扁平化（禁递归），防止环路死循环或超深链路触发浏览器栈溢出。
